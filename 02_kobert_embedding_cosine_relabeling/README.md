# 02. 감정 라벨 재태깅 시스템 설계 및 구현 (KoBERT + Cosine Similarity)

📅 **2024.03 - 2024.06 캡스톤디자인2 프로젝트**

## 📌 개요

본 폴더는 Q사 제품 리뷰 데이터에서 **별점 기반 감정 라벨링의 한계를 인식하고**,  
텍스트 의미 기반으로 감정 라벨을 **재정의(재태깅)** 하는 과정을 설계하고 구현한 내용을 담고 있습니다.

---

## 💡 문제 인식

- 초기에는 감정의 이진 분류를 별점 3점 이상 → 긍정, 1~2점 → 부정 으로 간단하게 라벨링
- 그러나 실제 예측 결과를 확인해보니 **3~5점 리뷰 중 부정적 내용 포함** 사례 다수
- 별점과 감정이 항상 일치하지 않는 문제 발견 → **별점만으로는 정답 라벨이 부정확함**

---

## 🧠 해결 방식

> 리뷰 텍스트를 KoBERT로 임베딩하고, 감정별 평균 벡터와의 유사도 비교를 통해  
> **가장 유사한 감정 라벨을 새롭게 부여**

### 구현 흐름:

1. `구매자평점`을 기준으로 감정 그룹 분리
   - 긍정 그룹: 4~5점
   - 부정 그룹: 1~2점
   - 3점 중립은 제외
2. 각 그룹 내 리뷰 텍스트를 **KoBERT 임베딩** (`[CLS]` 벡터 추출)
3. 그룹별 임베딩 벡터의 **차원별 평균 → 감정 대표 벡터 생성**
4. 각 리뷰를 임베딩 후, 감정 대표 벡터들과 **코사인 유사도 계산**
5. 가장 유사한 감정(`positive` or `negative`)으로 **`re_labeled` 컬럼 생성**
