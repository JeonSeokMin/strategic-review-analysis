# 감정 라벨 재태깅 설계 문서 (KoBERT + Cosine Similarity 기반)

## 🎯 문제 인식

기존 Q사 리뷰 데이터는 별점을 기반으로 감정 라벨이 지정되었음:  
- 3점 이상 → 긍정, 1~2점 → 부정

하지만 예측 결과를 확인해본 결과,
- 3~5점 리뷰 중 부정적인 내용이 포함된 경우 다수 존재
- → 정답 라벨 자체가 부정확하여 모델 성능 저하 초래

## 💡 해결 전략

별점이 아니라 **텍스트 의미(문장 임베딩)** 기반으로 감정 라벨을 재정의

### 핵심 아이디어:

1. **별점 그룹 나누기**
   - 긍정: 4~5점
   - 부정: 1~2점
   - 중립(3점)은 분석에서 제외

2. **KoBERT 문장 임베딩**
   - 각 리뷰를 KoBERT로 임베딩하고 `[CLS]` 벡터 추출

3. **감정 그룹 평균 벡터 생성**
   - 긍정 리뷰들의 임베딩 평균 → `pos_vec`
   - 부정 리뷰들의 임베딩 평균 → `neg_vec`

4. **각 리뷰를 재태깅**
   - 해당 리뷰를 임베딩한 뒤,
   - `pos_vec`, `neg_vec`와의 코사인 유사도 비교
   - 더 유사한 감정 벡터의 라벨로 재태깅

## ✅ 장점 및 기대 효과

- 별점 기준보다 텍스트 의미 기반이기 때문에 **더 정밀한 라벨링 가능**
- 오분류 감소, 모델 학습 정확도 향상
- 실전에서도 활용 가능한 감정 재태깅 전략

## 🧪 구현 환경

- 모델: `skt/kobert-base-v1` (HuggingFace)
- Python, Torch, Transformers, Scikit-learn, TQDM

## 📂 출력 결과

- `re_labeled_Q.csv`: `review`, `구매자평점`, `re_labeled` 컬럼 포함
- `re_labeled` 값은 `"positive"` 또는 `"negative"` 중 하나로 할당
