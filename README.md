### 소비자 리뷰 감정 분석에서 LLM 기반 전략 분석까지

## 핵심 연구: Q사 리뷰 분석을 위한 모델 선정

KCC 2024 연구에서는 실제 Q사 소비자 리뷰에 적용할 감정 분석 모델을 정해야 했습니다. 이를 위해 KoBERT와 KLUE-BERT를 비교했고, **당시 평가 조건에서 상대적으로 높은 F1-score를 보인 KoBERT를 Q사 리뷰 분석 모델로 선정**했습니다. 이후 감정 예측 결과 중 부정 리뷰의 주요 키워드를 추출·시각화하여 제품 개선 및 전략적 의사결정에 활용할 가능성을 탐색했습니다.

### 실험 결과 해석 시 유의사항

- 당시 Q사 리뷰의 별점 기반 라벨 분포는 **긍정 18,479건, 부정 71건**으로 극단적으로 불균형했습니다.
- 별점은 리뷰 텍스트에 나타난 감정과 항상 일치하지 않으므로, 별점 기반 라벨을 정답으로 간주하는 데 한계가 있습니다.
- 따라서 높은 평가 지표를 실제 환경에서의 일반적인 감정 분류 성능이나 부정 리뷰 탐지 능력으로 확대 해석하지 않습니다.
- **KoBERT 선정은 당시 비교 실험에 따른 연구상의 모델 선택**이며, 실서비스 수준의 성능 검증을 의미하지 않습니다.

이 문제 인식은 이후 KoBERT 임베딩과 코사인 유사도를 활용해 리뷰의 감정 라벨을 재검토하는 실험으로 이어졌습니다. 다만 재라벨링의 정확도 개선 여부는 별도 검증이 필요합니다.

## 후속 확장: 분류 결과에서 전략 분석으로

- **Claude 기반 분석:** KoBERT로 부정으로 분류한 리뷰를 입력해 주요 불만, 고객 인사이트, 제품·마케팅 개선 방향을 생성했습니다. LLM의 제안은 검증된 사업 성과가 아닌 분석 결과입니다.
- **ABSA·SWOT 워크플로:** GPT-4o로 리뷰의 속성(Aspect)·의견(Opinion)·감정(Sentiment)을 추출하고, SWOT 분석과 뉴스 검색·요약, 시장 전망 생성으로 확장했습니다. 현재 공개 코드는 당시 실험을 보존한 아카이브이며, 전체 워크플로의 즉시 재현은 제한됩니다.

- **데이터·모델:** Python, Pandas, Scikit-learn, PyTorch, Hugging Face Transformers, KoBERT, KLUE-BERT

## 프로젝트를 통해 배운 점

1. **모델 선정과 성능 일반화는 다르다.** 제한된 평가 조건에서 모델을 비교·선정할 수 있지만, 데이터 분포와 라벨 품질을 고려하지 않고 결과를 일반화해서는 안 됩니다.
2. **분석 결과의 활용 가능성을 함께 고민해야 한다.** 감정 분류에 그치지 않고 불만 키워드와 개선 방향을 도출하는 과정을 실험했습니다.
3. **실험의 한계도 결과의 일부다.** 클래스 불균형, 별점 기반 라벨링, LLM 출력의 검증 필요성 등을 후속 개선 과제로 인식했습니다.
