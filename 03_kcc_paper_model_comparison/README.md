# 03. 감정 분석 모델 비교 기반 기업 전략 분석 (KCC 2024)

**기간:** 2024.05~2024.06 · KCC 2024 학부생 논문경진대회 제출 연구

## 연구 개요

논문 **「소비자 리뷰 분석에 기반한 기업의 전략적 의사 결정을 위한 모델」**에 관한 자료입니다.

실제 Q사 제품 리뷰에 적용할 감정 분석 모델을 선정하기 위해 **KoBERT와 KLUE-BERT를 비교**했습니다. 당시 실험에서 상대적으로 높은 F1-score를 기록한 **KoBERT를 분석 모델로 선택**하고, 기업 리뷰에 적용하여 부정 리뷰의 주요 키워드를 추출·시각화했습니다.

- [논문 PDF](./KCC_학술지.pdf)
- 관련 학습·예측 코드: [01. KoBERT Fine-Tuning](../01_kobert_finetuning_prediction/README.md)

## 연구 흐름

1. AI-HUB 감정 분석 데이터 전처리
2. 원본 데이터 및 언더샘플링 데이터로 모델 학습
3. KoBERT와 KLUE-BERT의 당시 평가 결과 비교
4. Q사 리뷰 분석에 사용할 모델로 KoBERT 선정
5. 부정 리뷰 주요 키워드 추출 및 WordCloud 시각화
6. 소비자 불만 분석의 기업 의사결정 지원 가능성 검토

## 당시 보고된 모델 비교 결과

| 모델 | Precision | Recall | F1-score |
| --- | ---: | ---: | ---: |
| KoBERT | 0.99 | 0.93 | 0.96 |
| KLUE-BERT | 0.99 | 0.88 | 0.93 |

위 수치는 **당시 논문/발표에서 보고한 비교 결과**이며, 평가 데이터의 분포·라벨 생성 방식 및 클래스별 지표를 함께 고려해야 합니다. 수치만으로 KoBERT가 일반적인 실제 리뷰 감정 분석 환경에서 더 우수하다고 결론 내릴 수는 없습니다.

## 데이터 및 평가의 한계

- 당시 Q사 리뷰의 별점 기반 라벨은 **긍정 18,479건, 부정 71건**으로 극단적으로 불균형했습니다. 이런 환경에서는 높은 전체 지표가 부정 리뷰 탐지 능력을 충분히 설명하지 못할 수 있습니다.
- 별점으로 생성한 라벨은 리뷰 텍스트의 실제 감정과 일치하지 않을 수 있습니다.
- 따라서 **KoBERT 선정은 당시 비교 실험을 바탕으로 Q사 리뷰 분석을 진행하기 위한 결정**으로 설명합니다. 실서비스 수준의 성능 검증이나 검증된 기업 성과로 해석하지 않습니다.
- 후속 [임베딩 기반 재라벨링 실험](../02_kobert_embedding_cosine_relabeling/README.md)은 별점 라벨의 한계를 탐색한 시도이며, 정확도 개선이 검증되었다고 주장하지 않습니다.

## 연구 의의

BERT 기반 감정 분석 모델을 비교·선정하고, 기업 제품 리뷰의 부정 키워드를 분석함으로써 **소비자 불만 정보를 제품 개선과 전략적 의사결정에 활용할 수 있는 가능성**을 제시했습니다.

## 공개 코드 관련 안내

논문 당시의 실험 코드와 현재 저장소의 Hugging Face Transformers 기반 재구성 코드는 동일하지 않습니다. 공개 코드는 학습·예측 과정의 구조를 확인하기 위한 자료이며, 당시 논문 수치를 그대로 재현한다고 보장하지 않습니다.

## 담당 작업

AI-HUB 데이터 전처리 및 언더샘플링, KoBERT 학습 파이프라인 구성, Q사 리뷰 예측·시각화, 논문 작성 및 제출.
