# 03. 감정 분석 모델 비교 기반 기업 전략 분석 (KCC 학술지 정리)

📅 **2024.05 ~ 2024.06 KCC 학술지 제출용**

## 📌 개요

본 폴더는 2024 한국정보과학회 학부생 논문경진대회(KCC 2024)에 제출한  
논문 **「소비자 리뷰 분석에 기반한 기업의 전략적 의사 결정을 위한 모델」**의 내용을 정리한 폴더입니다.

---

## 📄 논문 PDF

- [`KCC_학술지.pdf`](./KCC_학술지.pdf)

---

## 🧠 연구 내용 요약

- **사용 데이터**: AI-HUB 감정 분석 데이터 (긍/부정 라벨), Q사 리뷰
- **사용 모델**:
  - `KoBERT`: SKT 제공 한국어 BERT
  - `KLUE-BERT`: KLUE 프로젝트에서 제공하는 BERT 모델

- **모델 학습**:
  - 원본 데이터와 언더샘플링 데이터 각각으로 모델 파인튜닝
  - 학습된 모델로 Q사 리뷰 감정 예측 수행

---

## 🎯 분석 목적

> 기업 제품 리뷰의 감정 분석을 통해  
> 소비자 불만 요소를 도출하고, 기업의 전략적 의사결정을 지원할 수 있는 기반 모델 탐색

- 예측 결과에서 **부정으로 분류된 리뷰 키워드 분석**
- WordCloud 및 주요 키워드 추출을 통해 **고객 불만 요인 시각화**

---

## 📊 실험 결과 요약

| 모델 | Precision | Recall | F1-score | 비고 |
|------|-----------|--------|----------|------|
| KoBERT | 0.99 | 0.93 | **0.96** | 성능 우수 |
| KLUE-BERT | 0.99 | 0.88 | 0.93 | 일반적 성능 |

> KoBERT가 높은 F1-score를 기록하여, **Q사 제품 리뷰 분석에 적합**하다고 판단

---

## 💡 의의 및 한계

- 학부생 수준에서 BERT 모델 비교 실험과 논문화 수행
- 실제 기업 데이터를 기반으로 분석 모델 적용
- **LLM 기반 분석 요소가 부족**하다는 심사위원 피드백을 받고,
  이후 Claude, GPT 기반 프로젝트로 확장 (4번, 5번 폴더 참고)

---

## ⚠️ 코드 구현 관련 안내

본 논문에 포함된 실험은 학부 졸업 당시의 환경과 라이브러리 기준으로 구현되었으며,  
현재 깃허브에 정리된 코드는 **Transformer 라이브러리 기반으로 구조화된 형태로 재작성**된 버전입니다.

> 즉, 논문 실험 당시에는 별도의 BERT 학습 코드 및 추출 코드가 사용되었고,  
> 본 저장소에서는 동일한 논리 구조를 바탕으로 HuggingFace 기반 구현으로 통합하였습니다.

이러한 재구성은 코드 가독성 향상, 재현성 확보, 후속 실험 연계(4, 5번 폴더) 목적에 기반하였습니다.
